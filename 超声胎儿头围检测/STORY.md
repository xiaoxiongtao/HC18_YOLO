# STORY.md · 《超声胎儿头围检测》教学课件

## ① 用户意图对齐

- **目标受众**：本科/研究生课堂教学（医学影像 AI / 智能医学工程方向），也适合项目组教学演示。
- **核心目标**：学生听完能理解——为什么头围自动测量有临床价值；HC18 数据集长什么样；如何把"掩膜标注"改造成 YOLO 可用的检测标注；YOLOv8/YOLO11 的网络架构与训练流程；如何用 mAP / MAD / DSC 等指标评价检测与测量精度；以及本项目的真实实验结论（mAP50≈0.995、MAD≈2.0mm）。
- **PPT 长度**：19 页（4 章 + 封面/目录/结论/致谢）。
- **视觉调性**：学术严谨、蓝白克制、证据驱动、教学清晰。
- **内容边界**：全部实验数据取自本项目 `runs/` 真实输出（comparison_metrics.csv、results.csv），公式来自项目代码（拉马努金椭圆周长近似）；不杜撰数据；不涉及临床诊断建议。

## ③ 页面大纲（关键字段见上表，此处补数据落点）

1. **封面**：《超声胎儿头围检测——基于 YOLO 的产前超声智能测量》，副标 YOLOv8 vs YOLO11 · HC18 挑战赛数据，汇报人：肖雄涛，2026-10。
2. **目录**：四章导览 + 一句话摘要。
3. **扉页01 临床背景与数据**：临床意义 / HC18 数据集两个要点。
4. **临床意义**：头围（HC）反映胎儿脑发育与孕周，异常提示小头/巨头风险；传统人工测量存在操作者差异；标准测量平面（丘脑平面）获取难度高 → 自动测量的价值（含义解释落点）。
5. **HC18 数据集**：999 训练 / 335 测试 / 806 病人 / 800×540 灰度 / HC 真值 44–346mm——说明数据覆盖不同孕龄与图像质量，按病人划分防止数据泄漏（业务影响落点）。
6. **扉页02 方法与技术路线**。
7. **技术路线总览**：掩膜标注 → 椭圆拟合 → YOLO 边界框 → 训练/对比 → 像素→毫米换算五步流程。
8. **数据预处理**：cv2.fitEllipse 拟合椭圆、外接矩形作检测框、YOLO 标签格式 `0 xc yc w h`、拉马努金二阶近似周长公式、按病人 8:2 划分；示例标签 `0 0.504 0.412 0.284 0.331`。
9. **YOLO 网络架构（hero）**：Backbone（Conv+C3k2+SPPF）→ Neck（PAN-FPN 多尺度融合）→ Head（解耦检测头）三段式 SVG 结构图，说明单阶段检测器"一图直达框+类别"的原理。
10. **训练配置**：相同超参数保证对比公平——epochs 100（早停 20）、imgsz 640、batch 16、lr0 0.01、mosaic/HSV/fliplr 增强、seed 42；YOLOv8 早停于 68 轮、YOLO11 早停于 60 轮。
11. **评价指标**：mAP50 / mAP50-95（框质量）、MAD（头围平均绝对误差 mm）、DSC（椭圆重叠）、Pearson r（相关性）——检测指标好≠测量误差小，需医学指标双重验证（管理启示落点）。
12. **扉页03 实验与结果分析**。
13. **训练过程曲线**：loss 快速收敛、mAP50 约 10 轮即达 0.99+ → 单类大目标检测任务相对容易，精度瓶颈在边界精细度（mAP50-95 收敛慢）。
14. **检测性能对比**：mAP50 0.995/0.995、mAP50-95 0.955/0.952、P 0.990/0.994、R 1.0/1.0、参数量 3.14M vs 2.60M、权重 6.5MB vs 5.5MB、推理 1.88ms vs 2.38ms——YOLO11 用更少参数达到同等精度，适合边缘部署（业务影响落点）。
15. **头围估计精度**：MAD 2.03mm vs 2.39mm、DSC 0.970/0.969、Pearson r 0.9992/0.9990——两模型相关性接近完美，MAD 均在 3mm 内，满足科研演示精度；文献参考值约 4–5% 对照说明本结果有竞争力。
16. **检测结果可视化（hero）**：验证集预测图（conf 0.7–1.0），展示典型困难样本（孕周小、伪影、体位偏移）。
17. **扉页04 总结与展望**。
18. **结论与展望**：结论三条（流程可行、两模型精度相当、YOLO11 更轻量）；展望三条（椭圆参数直接回归代替框拟合、引入分割任务、更多孕周亚组评估）。
19. **感谢页**：谢谢聆听 + 数据来源致谢（HC18 / Zenodo）。
